Sim Companies 聊天屏蔽 · 书签版

v3.4.0 · 不用装任何插件 · 不联网、不采集

电脑：拖过去就行

把这个按钮拖到书签栏：

🚫 聊天屏蔽

然后打开游戏聊天室，点一下这个书签。

手机

iOS Safari（书签版最顺的就是这条）

  1. 点上面的「📋 复制书签代码」
  2. 打开游戏页面 → 底部分享按钮 → 加入书签 → 存好
  3. 回到书签列表（底部那个 📖 图标）→ 右下角「编辑」→ 点刚存的那条 → 把 网址 整个换成刚复制的内容，名字改成「屏蔽」
  4. 以后用：在游戏聊天室里，点 📖 → 点「屏蔽」→ 右下角冒出面板

Safari 点书签就是在当前页面上跑，所以这条路很自然。

安卓 Chrome（麻烦，能装 X浏览器就别走这条）

先说为什么要绕：手机 Chrome 没有电脑上那种书签栏。 书签藏在菜单里，而从菜单点书签会新开一个页面 —— 那样代码就跑在一个空白页上，不是跑在游戏页面上，等于白点。

所以只能走地址栏：就是你平时输网址的那一条框 （在屏幕最上面；Chrome 新版可以设成放在最下面）。 它除了搜网页，也会搜你自己的书签 —— 这就是入口。
  1. 点上面的「📋 复制书签代码」
  2. 随便收藏一个页面（⭐）→ 进书签里编辑那一条 → 网址粘贴成刚复制的内容 → 名字改成 bl
  3. 打开游戏聊天室
  4. 在地址栏里打 bl（别按回车）—— 下面会冒出一条候选， 就是你那个书签
  5. 点那条候选 → 代码就在当前这个游戏页面上跑起来了

名字取 bl 只是因为要短而且独特 —— 取「屏蔽」的话候选里会混进一堆网页，翻不到它。

⚠️ 直接把代码粘到地址栏是没用的 —— Chrome 会把手打的 javascript: 吞掉（防钓鱼）。只能走书签候选这条路。
⚠️ 这是 Chrome 的一个副作用行为，不是正式功能，不同版本可能失效。 点了没反应就换下面的办法。
每次刷新页面要再点一次。书签版没法开机自启 —— 这是书签这种形式的硬限制， 不是没做。游戏内部切页面（路由）不用重点，只有整页刷新才要。
重复点也没关系：已经在跑的话它只会把面板叫回来，不会叠第二个。
可能被网站的 CSP 挡住。多数浏览器对书签是放行的，但这事得真机试才算数。 点了完全没反应，就说明这条路在你的浏览器上走不通 —— 改用下面的办法。

安卓推荐：干脆装油猴，别折腾书签

装了之后功能完全一样，而且不用每次刷新都点一次，也没有上面地址栏那一堆麻烦。

  • 安卓：X浏览器（国内应用商店就有，内建油猴）／ Via ／ Alook ／ Firefox for Android + Tampermonkey
  • iOS：Safari 装 Userscripts（免费开源）／ Stay ／ Orion 浏览器
  • ⚠️ 网上老教程里满地都是的 Kiwi 浏览器，2025 年初已经停更归档了，别装

然后装 simco-chat-block.user.js 就行。

一句话选路：安卓 → 装 X浏览器用油猴版； iOS → 书签版（Safari 上很顺）；实在都不行 → 安卓 Chrome 那条地址栏的办法。

怎么用

  1. 面板上点「＋ 屏蔽一个人」
  2. 去聊天里点那个玩家的名字（不是点消息正文）
  3. 他的消息就不显示了。名字后面的「挡了 N」是实时的 —— 一直是 0 就说明没生效

要屏蔽第二个人，再点一次「＋ 屏蔽一个人」。不会把前一个顶掉（v3.3.0 修的就是这个）。
